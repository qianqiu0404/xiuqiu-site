怎么验证的

  • 重启程序并换会话后，账户 A 仍只看到未发货订单。账户 B 看到自己的全部订单，偏好为空。
  • 源码测试另行验证了账户隔离。清除账户 A 的一项或全部偏好后，账户 B 的设置和写入时间照旧。
  • 检查写入值、完整数据库和客服回答，确认没有原始手机号。
  • 两次导出的 JSON 逐字节一致，且没有本机路径、主机名或用户名。
