2026-11-13 按已确认的 V3.1 展示版本迁入 Vue。首页沿用原作品集的纸感、森林绿与青柠色，颜色集中于 `src/design/tokens.css`，页面样式限定在 `.resume-page`。浅深外观与站点其他页面共享偏好。

- `/radar`、`/market-radar`、`/articles`、`/profile` 以及原工程与项目 URL 继续保留。首页与情报页均可互相进入。
- `shared/site.ts` 定义主域名 xoqiu.cn；订阅、网站地图和静态分享元信息从既有生成器更新。已发布的市场研究包保留原始字节和链接，原 Vercel 域名继续服务旧入口。

## 内容与边界

`src/features/resume/records.json` 是完整目录，`notes.json` 是审核过的公开详情，按需加载；Vue 页面与组合函数管理搜索、分类、历史开关、详情、复制链接、键盘与浏览器历史。标题和目录筛选逻辑在 `presentation.ts`，行为检查接入 `test:home`。

目录同时包含个人作品、团队本人参与、学习实验和历史资料，不代表 29 个已运营产品。公司、正式岗位和时间线仍待本人提供，不补造。已有作品的实现、模拟验证、实际部署及用户验收边界保留原文。

知识地图的稳定详情 ID 为 `wildheart`。它是私有项目，公开版本仅包含虚构的组织结构示意、功能方法与私有声明，不包含该项目的源码、原始资料、真实笔记或下载入口。`public/resume/` 仅放本次允许公开的七个展示素材。

## 发布与恢复

执行完整 `npm run build`，在 `vite preview` 检查桌面、375px、浅深外观、所有详情、筛选与旧页面往返。经 PR 检查合并后，以 main 的完整提交值运行现有 `release-controller.yml`。本次简历发布不启用市场通知或 worker。

生产切换前记录原 READY 部署；必要时通过既有发布恢复流程回到该部署。域名只增加根域和 www，保留 market 与现有隧道记录。知识地图的私有项目自身不参与站点发布。
